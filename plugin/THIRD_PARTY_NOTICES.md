# Third-party notices

The package currently uses Node.js built-in modules only, including `node:sqlite`, `node:crypto`, and the standard filesystem and process APIs. No third-party runtime package is bundled.

The campaign profiles name skills from [Superpowers](https://github.com/obra/superpowers) (Jesse Vincent, MIT) and [Co-Researcher](https://github.com/poemswe/co-researcher) (poemswe, MIT). This package does not copy or redistribute their source. Install them from upstream in each client that runs a campaign profile requiring them.
